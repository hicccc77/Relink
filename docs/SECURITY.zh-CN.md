# 安全与隐私

[English](SECURITY.md) | [简体中文](SECURITY.zh-CN.md)

## 数据边界

Agent 只能看到 `RelinkDataProvider` 返回的内容。Provider 应在查询层完成身份、租户、行级权限和字段脱敏；不要让 Agent 进程直接继承数据库管理员凭据。

## 模型数据传输

Runtime 在收到运行请求且模型配置完整之前不会调用模型。运行开始后，模型服务会收到系统提示、用户问题，以及 Agent 实际选择的原始记录片段、媒体转写或网页结果。

部署方应明确告知用户传输范围，并为不同租户使用独立 Provider、密钥和 `dataDir`。

## 持久化

`dataDir` 保存运行快照、追加日志、对话索引、记忆和可选的原文页缓存。原文页缓存使用调用方提供的 `cacheEncryptionSecret` 通过 AES-256-GCM 加密；没有密钥时不会将原文页写入磁盘缓存。

生产环境应把该目录放在受限磁盘，并配置备份、保留期和删除策略。不要把 `.relink` 提交到版本库。

## HTTP 与 MCP

HTTP 服务默认只监听回环地址，但没有内置认证。远程部署必须增加 TLS、认证、授权、速率限制、请求体上限和审计。

MCP stdio 通道应只由受信任的集成程序启动，并妥善保护模型密钥和数据文件路径。

## 内容风险

关系分析输出是对可观察记录的证据化解释，不是心理诊断、动机证明或事实裁决。不要将输出直接用于招聘、信贷、惩罚、健康或其他高风险自动决策。

媒体和原始记录可能包含恶意提示。Provider 与集成程序应把外部内容视为不可信数据，并在进入 Agent 前实施必要的验证、脱敏和访问控制。
